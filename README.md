# Tic-Tac-Toe (5x5)
A Java implementation of Tic-Tac-Toe on an expanded 5x5 board, built to 
strengthen object-oriented programming and game logic design.

## 📸 Preview
> Add a screenshot or terminal capture of gameplay here.

## ✨ Features
- 5x5 grid (larger than standard 3x3, requiring updated win-condition logic)
- Two-player gameplay
- Win/draw detection
- Clean OOP structure

## 🛠️ Built With
- Javas

## 💻 Getting Started
1. Clone the repository.
```bash
git clone https://github.com/diro25/TicTacToe5x5.git
```
2. Navigate to the project folder.
```bash
cd TicTacToe5x5
```
3. Compile and run.
```bash
javac src/Main.java
java src/Main
```

## 📚 What I Learned
During this project I practiced:
- Object-oriented design (Board, Player, Game classes)
- Adapting win-condition logic for a non-standard grid size
- Managing game state and turn logic cleanly
